# Brightness Tray — лёгкий регулятор яркости и синего канала

Минималистичное приложение (одна кнопка в трее + два вертикальных слайдера)
для быстрой регулировки **яркости монитора** и **синего канала** («отдых для глаз»).

## Возможности
- Иконка-«солнышко» в системном трее.
- **Клик левой кнопкой мыши** по иконке открывает/закрывает панель.
- Панель появляется рядом с треем (правый нижний угол), всегда поверх окон
  и автоматически прячется при потере фокуса — как нативный поповер.
- Вертикальный слайдер **Яркость** (10–100 %).
- Вертикальный слайдер **Синий** (70–100 %) — мягкий фильтр для отдыха глаз.
- Быстрые пресеты: «Отдых глаз» (яркость 90 %, синий 70 %),
  «Чтение» (яркость 80 %, синий 90 %), «Сброс» (100 % / 100 %).
- Контекстное меню трея: показать панель, макс. яркость, ночной режим,
  сброс гаммы, выход.

## Как это работает
| ОС        | Яркость                                   | Синий                        |
|-----------|-------------------------------------------|------------------------------|
| Windows   | GDI `SetDeviceGammaRamp` (программная гамма, плавная до 10 %) | тот же гамма-рамл, канал B |
| Linux/X11 | `xrandr --output ... --gamma r:g:b`       | там же, канал g/b            |
| macOS     | утилита `brighter`, если установлена      | только UI (best effort)      |

> Примечание: аппаратная яркость монитора через WMI намеренно не
> используется — у большинства мониторов она имеет порог ~50 %, из-за
> чего значения ниже 51 % выглядели одинаково. Программная гамма
> масштабирует экран плавно по всему диапазону 10–100 %.

## Установка и запуск
```bash
pip install -r requirements.txt
python brightness_tray.py
```

На Linux нужен X11 (сессия с треем/appindicator). На Wayland без LayerShell
трей может быть недоступен — используйте X11/XWayland-сессию.

## Автозапуск (Windows)
Создайте ярлык на `pythonw.exe brightness_tray.py` в папке
`shell:startup` (Win+R → `shell:startup`).

## Сборка в .exe (опционально)
```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name BrightnessTray brightness_tray.py
```
